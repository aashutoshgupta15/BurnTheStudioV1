# BurnTheStudio

Website for BurnTheStudio. Burn the brief. We build your idea.

A single static page (`index.html`) with a live 3D studio floor built with three.js. No build step and no backend.

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.

## Deploy

Any static host works (GitHub Pages, Vercel, Netlify). For GitHub Pages, go to Settings > Pages, choose the `main` branch and the `/ (root)` folder.

## Before launch

- Replace the placeholder email `hello@burnthestudio.com` (in the contact section).
- Replace the illustrative briefs with real case studies.
